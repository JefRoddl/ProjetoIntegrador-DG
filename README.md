# projetoIntegradorTurmaUm
> Uma página inspirada no design e funcionalidades principais do site oficial da Nike.

## Sumário
- Página desenvolvida como parte do Projeto Integrador do curso de Desenvolvimento Web da Digital House
- O objetivo foi recriar uma experiência de e-commerce moderna, com organização de produtos, busca por categorias e uma interface responsiva inspirada na identidade visual da Nike.

## Tecnologias Utilizadas
- HTML
- CSS
- Node.js
- JavaScript
- Express
- MVC
